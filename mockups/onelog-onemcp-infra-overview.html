④ 7 Workflows đang chạy

Mỗi flow = 1 câu chuyện end-to-end

1 · Log ingest → query
core
Fleet rsyslog→Vector :514u/6514t→VictoriaLogs→VMUI / LogsQL
Vector parse RFC3164/5424 + JSON. Retention theo VL_RETENTION (default 7d). Ops query VMUI hoặc hỏi chat có citation.
2 · Semantic indexing (WARN+)
indexer
Vector filter WARN+→NATS logs.warn→Indexer Drain3→Qdrant
Drain3 gom log về template · embed text-embedding-3-small · mcp-semantic search top-K + ví dụ entry.
3 · MCP tool invocation
chat
Chat (OWUI / Claude Desktop)→mcpo (OWUI) / stdio (CD)→mcp-vl · mcp-semantic
Response gồm VMUI deep link (VMUI_BASE_URL) + citation [service:host:ts]. Claude Desktop dùng prompt caching giảm cost.
4 · LLM provider abstraction
cost
OpenWebUI→LiteLLM :4000→Anthropic · OpenAI · Gemini · DeepSeek
Route theo LLM_MODEL prefix. Cost log stdout → Vector → VL → Grafana dashboard + alert quota.
5 · OneMCP KB bridge (incident memory)
bridge
OpenWebUI Function/Action→OneMCP /api/mcp/*→Postgres+pgvector
Function onemcp-tools.py: search KB trước khi trả lời. Action "📚 Save": submit modal → /api/mcp/artifacts. Header X-Onemcp-User attribution.
6 · KB.inet (Bookstack) retrieval
kb
OWUI Function bookstack-tools.py→kb.inet.vn/api/*
3 tool whitelist: search_pages · get_page · get_recent_changes. Không qua mcpo — Python Function trực tiếp, docstring giàu để tránh hallucination.
7 · Alerting → Telegram (+ OneMCP incident)
alerts
vmalert (LogsQL rules) · vmalert-metrics (Prom rules) → Alertmanager :9093 → Telegram · 3 topics → OneMCP /api/webhooks/alerts
Rules: infra/vmalert/{rules.yml, metric-rules.yml}. Telegram topics: General · LLM cost · Client-Server fleet. OneMCP webhook lưu incident vào KB → tái sử dụng lần sau.
