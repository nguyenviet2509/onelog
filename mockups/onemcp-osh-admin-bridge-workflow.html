📋 osh_admin handoff checklist 6 items để unblock P5d

Chi tiết từng bước dev osh_admin cần làm để OneMCP swap từ mock sang prod. Effort estimate ~1-2 tuần (SDK integrate là phần lớn).

1. Register app osh_admin trên Central RBAC portal

Central RBAC là source of truth cho permissions. App osh_admin phải có identity trên Central để publish manifest + assign role.
1. Login https://central-rbac.inet.vn (admin role) 2. Menu Apps → New app → tên "osh_admin", slug "osh_admin" 3. Wizard tạo Zitadel project auto (hoặc adopt existing) 4. Copy app token (format rbac_<8>_<24>) → env osh_admin backend

2. Publish manifest .well-known/rbac-permissions.json

Central RBAC portal fetch manifest từ endpoint này để know permissions + default_roles. Auto-wire khi apply.
GET https://osh_admin.domain/.well-known/rbac-permissions.json → { "app_slug": "osh_admin", "version": "1.0.0", "permissions": [ { "id": "osh_admin:tool.create_waf", "description": "Create WAF rule blocking IP/domain" }, { "id": "osh_admin:tool.create_rate_limit", "description": "Set request rate limit" }, { "id": "osh_admin:tool.query_access_log", "description": "Query HTTP access logs" } ], "default_roles": [ { "id": "osh_admin.viewer", "permissions": ["osh_admin:tool.query_access_log"] }, { "id": "osh_admin.operator", "permissions": ["osh_admin:tool.create_waf", "osh_admin:tool.create_rate_limit", "osh_admin:tool.query_access_log"] } ] }

3. Integrate central-rbac-client SDK trong backend osh_admin

SDK có sẵn LRU cache 60s + circuit breaker + epoch poller 10s built-in. Chỉ cần init 1 lần global instance.
// Node/TypeScript example (SDK repo: d:/Vietnt/Project/onelog/central-rbac-client/nodejs) import { CentralRbacClient } from 'central-rbac-client'; const rbac = new CentralRbacClient({ baseUrl: process.env.CENTRAL_RBAC_URL, // https://central-rbac.inet.vn appSlug: 'osh_admin', token: process.env.CENTRAL_RBAC_TOKEN, // rbac_xxx from step 1 cacheMaxAgeMs: 60_000, // default OK circuitBreaker: { threshold: 5, resetMs: 30_000 }, });

4. Middleware verify X-Onemcp-User-Sub + gate per-endpoint

Đây là RBAC gate thật — thay thế fake gate trong mock. Fail-closed: nếu SDK error → 503.
// Express example — apply cho các route bridge OneMCP call app.use(async (req, res, next) => { const sub = req.headers['x-onemcp-user-sub']; if (!sub) return res.status(401).json({ error: 'missing X-Onemcp-User-Sub header' }); const routePerm = { 'POST /waf/rules': 'osh_admin:tool.create_waf', 'POST /rate-limits': 'osh_admin:tool.create_rate_limit', 'GET /access-logs': 'osh_admin:tool.query_access_log', }; const requiredPerm = routePerm[`${req.method} ${req.path}`]; if (!requiredPerm) return next(); try { const perms = await rbac.resolve({ sub, tenant: 'default' }); if (!perms.includes(requiredPerm)) { return res.status(403).json({ error: 'forbidden', missing_permission: requiredPerm }); } next(); } catch (e) { // Fail-closed: circuit open hoặc Central down → deny res.status(503).json({ error: 'authorization service unavailable' }); } });

5. Expose prod endpoint URL + cấp bearer service-to-service cho OneMCP

OneMCP cần base URL + bearer để swap mock → prod. Bearer dùng chỉ cho OneMCP (service-to-service, không phải user OAuth).
Deliverables sang OneMCP admin: 1. Base URL prod (VD https://gateway.onepanel.vn:8443/osh_admin) 2. Bearer token dài (min 32 chars random) — deliver qua Bitwarden/1Password KHÔNG email/chat 3. Confirm 3 endpoint paths khớp OneMCP đã register: - POST /waf/rules → body {domain, ip, rules?} - POST /rate-limits → body {domain, limit_rps} - GET /access-logs → query {domain, since?, limit?} 4. Confirm param_schema field names match (case-sensitive)

6. Confirm exposure model → decides security mechanism

Trust boundary OneMCP ↔ osh_admin phụ thuộc network isolation. Public exposure cần HMAC (thay plaintext trust).
Trả lời 1 trong 3 options: A. LAN-only (osh_admin chỉ accept traffic từ OneMCP VPC/subnet) → IP whitelist middleware trên osh_admin + firewall block internet → Plaintext X-Onemcp-User-Sub header OK → Chọn nếu deploy trong same VPC B. Public (osh_admin expose qua public gateway) → CẤM plaintext trust — attacker cùng subnet gateway có thể spoof sub → REQUIRE HMAC signed X-Onemcp-User-Sub (shared secret Vault) → +1-2d scope creep MVP OneMCP cần add HMAC compute C. Hybrid (internal path + public gateway) → Path-based routing: public → HMAC, internal → IP whitelist → Cần document per-bridge trong metadata
Sau khi 6 items done: OneMCP admin thực hiện P5d (~30 phút): edit upstream osh_admin qua /admin/tool-bridges UI → change base_url + bearer → save → smoke happy path 1 prompt qua Claude Desktop → verify correlation ID chain trong logs 2 systems.
