Sepay webhook signature validation flow

published v3 · Updated by chuongdt 2 phút trước · Space: Support

Runbook mô tả cách verify chữ ký HMAC-SHA256 cho webhook đến từ Sepay, xử lý idempotency và fallback khi gateway timeout.

1. Cấu hình secret

Secret nằm trong SEPAY_WEBHOOK_SECRET ở env của service onelog-action. Rotate 90 ngày/lần theo lịch với PM.

2. Verify signature

const sig = req.headers['x-sepay-signature'];
const body = JSON.stringify(req.body);
const expected = crypto
  .createHmac('sha256', SECRET)
  .update(body).digest('hex');
if (!crypto.timingSafeEqual(
  Buffer.from(sig), Buffer.from(expected))) {
  return res.status(401).send('bad sig');
}

3. Idempotency

Sepay có thể retry nhiều lần với cùng transaction_id. Dùng Redis SETNX với TTL 24h để deduplicate.
